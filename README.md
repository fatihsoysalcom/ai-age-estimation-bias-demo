# AI Age Estimation Bias Demo

This Python script simulates an AI age prediction model to demonstrate how biases in training data can lead to inaccurate predictions, particularly for certain demographic groups. It highlights that AI errors in age estimation are often due to bias, not just a lack of accuracy.

## Language

`python`

## How to Run

Run the script using a Python interpreter: `python age_bias_demo.py`
